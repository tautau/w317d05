# w317d05

A small city-building game in development, inspired by classic SimCity-style city builders.

The project is being rebuilt as a Node.js application and deployed on Vercel.

## Development

Requirements:

- Node.js 24

Run locally:

```bash
npm install
npm run dev
```

The current build is an early welcome screen. The long-term goal is a playable city simulation where you can lay out a city, build neighborhoods and infrastructure, and watch it grow.

## Deployment

The project is configured for Vercel's Node.js runtime. Pushes to the connected GitHub repository trigger Vercel deployments automatically.
